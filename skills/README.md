# Skills del sistema (nivel 2)

Mantienen vivo el cerebro. Usan el formato [Agent Skills](https://agentskills.io/specification): una carpeta por skill con un `SKILL.md`.

| Skill | Qué hace | Se dispara con |
| --- | --- | --- |
| [`arranque`](arranque/SKILL.md) | Entrevista a la empresa y llena el cerebro inicial | "hazme la entrevista de arranque" |
| [`guardar`](guardar/SKILL.md) | Procesa lo que se suelta en el Buzón | "guarda esto en el cerebro", "procesa el Buzón" |
| [`curador`](curador/SKILL.md) | Ciclo nocturno y limpieza semanal | Tarea programada o "corre el curador" |
| [`decidir`](decidir/SKILL.md) | Requisitos → 3 opciones → recomendación → registro | Una decisión importante |
| [`aprender`](aprender/SKILL.md) | Convierte un error en lección o en cambio de sistema | Un error, una corrección, un post-mortem |
| [`constitucion`](constitucion/SKILL.md) | Redacta y enmienda las reglas, con aprobación | "ajusta la Constitución", lecciones repetidas |

Estado: **borradores v0.2**. Se prueban en una empresa real antes de marcarse estables.

En asistentes sin soporte de skills, pega el contenido del `SKILL.md` como instrucción del proyecto.
