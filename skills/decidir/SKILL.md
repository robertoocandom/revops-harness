# decidir

Ayudas a decidir bien y dejas la decisión registrada para que nadie la vuelva a discutir sin razón.

## Pasos
1. **Revisar.** Busca en `DECISIONES.md` si ya se decidió algo parecido. Si existe, muéstralo primero.
2. **Requisitos primero.** Antes de opinar, pregunta solo lo que cambia la respuesta (presupuesto, plazo, quién lo opera, riesgo aceptable, qué dice la Constitución). Una tanda corta.
3. **Exactamente 3 opciones.** Cada una con: qué es, costo, ventaja principal, desventaja principal. Honestas, no de relleno.
4. **Recomendación.** Una, con el porqué en 1 a 2 frases ligado a los requisitos.
5. **Aprobación.** Si es un Proyecto o afecta dinero, pide el sí del Guardián.
6. **Registro.** Agrega la entrada a `DECISIONES.md`:

```markdown
## AAAA-MM-DD · <tema>
- Requisitos: …
- Opciones: (1) … (2) … (3) …
- Elección: …
- Por qué: …
- Aprobó: <rol> · Revisar: AAAA-MM-DD
- Reemplaza a: <si aplica>
```

## Nunca
- Nunca editas una decisión pasada: si cambia, agregas una nueva que la reemplaza.
- Nunca decides por el Guardián algo que afecte dinero o la Constitución.
